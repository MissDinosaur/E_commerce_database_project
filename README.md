# E-Commerce Transaction Analysis Pipeline

## Project Overview

This project aims to build a database management system of e-commerce transactions from the Olist dataset and then analize the data to detect potential fraud and provide insights into customer purchasing patterns. The pipeline ingests data in a simulated real-time environment, processes it using big data tools, and applies machine learning for fraud detection and analytics.

When you build and run this project in docker, the zookeeper, Kafka, Spark, Spark streaming services, and database initialization part, data ingestion part will automatically run. 

After database initialization part is finished, Olist data will be migrated from SQLite to Posgres. In the meantime, some data generated by the python codes will be stored into MongoDB and Neo4J according to their data structure.

After data ingestion part is completed, ML tranining service will start and create a model for the backend use.

In addition, for data collection part, the usage of Kafka + Spark streaming, you need to run one comand to trigger it manually. The command is provided below.

Apart from that, this project has made a Data-checking website in Streamlit. In this website, yoiu can easily check the tables of PostgreSQL, MongDB and Neo4J. But you also need trigger it manually by one comand given as below.

Last, this project is containerized. All the services are containeraized by docker.

## Technologies Used

- **Data Collection**: Apache Kafka + Spark streming for real-time data streaming 
- **Data Ingestion/Storage**: PostgreSQL, MongoDB, Neo4j.
- **Data Processing**: Neo4j.
- **Machine Learning**: Scikit-learn, TensorFlow.
- **Visualization**: Python scripts for generating graphs from machine learning models.
- **Data-checking website**: Streamlit

## Installation

### Prerequisites

- Docker
- Python 3.11
- Access to a Kafka server (can be local or remote)

### Setup

1. Clone the repository:
   ```bash
   git clone [repository-url]
   cd [project-folder-name]
   ```

2. Build Docker containers:
   After run this command, .

   ```bash
   docker-compose -f docker-compose.yml up    # build images and create, run contianers
   ```

   If you wanna stop and remove sontainers, you can

   ```bash
   docker-compose -f docker-compose.yml down    
   ```

## Running the Project

1. Start the data collection:
   ```bash
   docker exec -it [spark-streaming-job container ID] bash 
   
   python Kafka_produce_data.py '[{"customer_id": "C101", "product_id": "P021", "order_id": "O231"}, {"customer_id": "C002", "product_id": "P002", "order_id": "O002"}]'   # Make Kafka to sent then stream data you just pass to Spark streaming
   ```

2. Run the Spark processing:
   ```bash
   spark-submit scripts/process_data.py
   ```

3. Execute machine learning models:
   ```bash
   python scripts/run_models.py
   ```

4. Generate visualizations:
   ```bash
   python scripts/generate_graphs.py
   ```
5. Generate data-checking website:
   ```bash
   cd streamlit
   streamlit run showtime.py
   ```
